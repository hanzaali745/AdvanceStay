## ✍️ Writing Process Per Post

### Phase 1: Research (1-2 hours)
- Read top 3-5 ranking posts for the topic
- Note their H2 structure, gaps, angles
- Read "People Also Ask" section (becomes FAQ)
- Check Reddit/forums for common questions
- Validate demand (Google Keyword Planner)

### Phase 2: Outline (30 minutes)
- Primary keyword + search intent
- H1 title (with keyword)
- H2 structure (question-style)
- Key points per section
- FAQ questions
- Affiliate integration points

### Phase 3: Write (2-3 hours)
- Answer-first opening (50-200 words)
- Each H2 section (200-300 words)
- Include examples, screenshots, links
- Table with comparison/specs
- FAQ answers (50-100 words each)
- Author bio + CTA

### Phase 4: Edit & Format (1 hour)
- Fix em-dashes, awkward phrasing
- Add internal links
- Verify all links work
- Screenshot sizes optimized
- Alt text complete
- Meta description ready

### Phase 5: Publish (30 minutes)
- Upload to HTML file
- Add featured image
- Set meta title/description
- Add to sitemap.xml
- Submit to Google Search Console
- Share on social media

**Total per post:** ~7-8 hours (research + writing + editing)
